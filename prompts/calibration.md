These are corrections partners made to an AI screening system's scores, each with a one-line reason:

{{corrections}}

Find patterns shared by 3 or more corrections (for example "missing repeat rate was under-penalised for consumer brands", or "system over-weighted founder credentials in deeptech"). For each pattern, write:
- `pattern`: what the system keeps getting wrong, in one sentence.
- `note`: a short instruction the scorer should follow next time (one or two sentences, phrased as guidance, not a hard rule).
- `scope`: the sector / businessModel / criterion it applies to (null for any).
- `based_on_ids`: the correction ids (#n) that support it. There must be at least 3.

Return an empty list if no pattern is shared by 3+ corrections. Do not invent patterns.
